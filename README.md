# Bikra Abna — Engineering Portfolio (2026 Edition)

Personal engineering portfolio of **Bikra Abna Filqiyast Dzaki**, Fullstack Developer Intern at **PT Tiga Serangkai Pustaka Mandiri**.

Engineered on strict **Swiss Editorial Design Discipline**: pure contrast, asymmetric typographic hierarchy, and tactile scroll-driven narrative choreography. Zero AI-slop corporate bloat, zero scroll-hijacking.

---

## Architecture & Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Library:** [React 19](https://react.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict type-safety)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Typography:** Uncut Sans (Display narrative) & Martian Mono (Technical telemetry)
- **AI Integration:** Vercel AI SDK (`@ai-sdk/google`) — Jackson Bot terminal agent
- **Motion & Storytelling:** Lightweight Native Web APIs (IntersectionObserver, hardware-accelerated 3D transforms, CSS ticker marquees, living liquid timeline track)

---

## Narrative & Motion Features

1. **Dossier Access Protocol (Opening Sequence):** Interactive perforated tear-off ticket reveal on fresh session visits.
2. **Kinetic Horizontal Typography:** Hero identity shifts dynamically along the horizontal axis linked to native window scroll velocity.
3. **Parallax Curtain Wipe Showcase:** Project mockups reveal through optical frame windows with subtle depth parallax.
4. **Living Red Thread Timeline:** Career chronology spine fills dynamically with signal-red ink as users progress down the record.
5. **Real-time Studio Telemetry:** Live Jakarta timekeeper (WIB) and running system broadcast tickers.
6. **Jackson Bot Terminal:** AI-powered conversational interface delivering instant verification of credentials and project architecture.

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
